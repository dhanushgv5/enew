# E-Commerce Frontend (Next.js 15 + Tailwind)

Modern UI for the NestJS e-commerce backend.

## Features

- Clean, responsive UI following good UX principles
- JWT auth with automatic token refresh
- Product listing + search + detail
- Cart with quantity management
- Checkout → Order creation
- Order history
- Role-aware navigation (Admin link for admins)

## Quick Start

```bash
cp .env.local.example .env.local
npm install
npm run dev
```

Open http://localhost:3000

Make sure the backend is running on port 4000.
